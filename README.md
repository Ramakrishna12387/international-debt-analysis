# International Debt Analysis System Using Python, SQL & Streamlit

## Overview
An end-to-end data analytics pipeline to clean, store, query, and visualize international debt statistics from the World Bank.

## Tech Stack
* Python (Pandas, SQLAlchemy, PyMySQL)
* MySQL (Relational Schema & 30 Analytical Queries)
* Visualization (Plotly, Matplotlib, Seaborn)
* Dashboard (Streamlit)

## Deliverables Included
1. `data_pipeline.py` - ETL script for data ingestion, cleaning, and MySQL insertion.
2. `schema.sql` - Relational table structure with Primary & Foreign Key constraints.
3. `queries_30.sql` - 30 structured SQL analytical queries (Basic, Intermediate, Advanced).
4. `app.py` - Interactive Streamlit web dashboard.
5. `eda_report.ipynb` - Exploratory Data Analysis with visualizations.
